# AWS CI/CD Raspberry Pi Portfolio

An automated full-stack project featuring a live interactive portfolio, real-time Raspberry Pi 5 telemetry simulation, and automated GitHub Actions CI/CD deployment.

### 🚀 Live Demo
Visit the live portfolio website: [https://ate-awscourses.github.io/aws-CI-CD-raspberrypi/](https://ate-awscourses.github.io/aws-CI-CD-raspberrypi/)

### 🛠️ Architecture & Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Multi-tab layout & Cyber Terminal CLI)
* **Telemetry:** Simulated edge node metrics (CPU temperature, memory, disk I/O)
* **CI/CD Pipeline:** GitHub Actions workflow automating static site deployment to GitHub Pages
* **Infrastructure:** Raspberry Pi 5 / Linux environment integration
